Save and Manage Bins
Bin visibility

Public bins can be read without a key. Changing visibility and saving updates the selected bin; making a keyless Public bin private requires a new owner key.

Bins are automatically deleted after 30 days without a successful GET, PUT, or PATCH. Reading or updating a bin resets its inactivity timer.

Authentication

Private bins require the owning key for reads. Public bins saved without a key use this browser's HttpOnly owner cookie for updates and deletes. To manage public bins from another client, create them with an account key.

Copy this key to a password manager before leaving or refreshing the page. A new key creates a different account and cannot restore access to existing bins.

Saved bins

Bins saved in this browser will appear here.

    Bin IDs are remembered in this browser only. The secret key is never saved here.

    API CRUD Tester

    GET reads a bin; POST can run a nested-array lookup; PUT replaces it; PATCH merges top-level object fields. POST, PUT, and PATCH use this request body.

    Headers

    Public GET does not need a key; this browser's HttpOnly owner cookie manages keyless public bins. Enter X-Secret-Key here for private GET or to manage account-owned bins from another client. The tester-only value is kept in page memory, not browser storage.

    Never put a secret key in the endpoint URL or query string.

    How to use
    
      
      
        
    1. Paste or upload JSON. Save bin validates it and formats it before sending.
      2. 
        
    2. Choose Public or Private in Save and Manage Bins, then save. Changing visibility updates the selected bin. If Private has no key, Save generates one and pauses; copy it with the Copy button, then press Save bin again to create or update the bin.
      3. 
        
    3. Your bin is saved on the server. The saved-bin list on this browser keeps only its ID and visibility, and refreshes when the page opens or returns to focus. Missing bins are removed and visibility is updated from the server. Use loads a bin into the editor; Delete removes it from the server and this browser's list.
      4. 
        
    4. The secret key is never stored in the browser. Public reads need only the ID; keyless public bins are managed by this browser's HttpOnly cookie. Private bins require the owner key.
      5. 
        
    5. Bins expire after 30 days without a successful GET, PUT, or PATCH. Any of those operations resets the inactivity timer.
      6. 
        
    6. Use the API CRUD Tester for manual requests; its Results section appears in the same panel. Paste either a bin ID or an API path.
      7. 
        
    7. Live API Logs are public-safe and run for up to 10 minutes. Stop resets the timer for the next start; sessions also stop after 5 minutes idle. Clear empties this viewer, and new events auto-scroll to the latest.
      8.

        Nested lookup example
        
    Choose POST, set the endpoint to /api/bins/YOUR_BIN_ID/query, and put this JSON in the API tester's Request body. One match returns an object such as { "Points": 5 }; multiple matches return an array of objects. A plain Blueprint string must match exactly; use { "contains": "Dodo" } for a case-sensitive partial match. Use the full Blueprint text when matching names could be ambiguous. The level field automatically finds the Award whose MinLevel/MaxLevel range contains that level.
    
        
    {
  "steps": [
    {
      "array": "DinoRewards.Dinos",
      "where": { "Blueprint": { "contains": "Dodo" } }
      "where": {
        "Blueprint": "Blueprint'/Game/PrimalEarth/Dinos/Dodo/Dodo_Character_BP.Dodo_Character_BP'"
      }
    },
    {
      "array": "Award",
      "level": 25,
      "select": "Points"
    }
  ]
}
    
      
    
      
    
        Private GET, PUT, and PATCH header examples
        
    Replace YOUR_KEY and YOUR_BIN_ID. Public GET requests can omit the key header.
    
        
    GET /api/bins/YOUR_BIN_ID
X-Secret-Key: YOUR_KEY

PUT /api/bins/YOUR_BIN_ID
X-Secret-Key: YOUR_KEY
Content-Type: application/json

PATCH /api/bins/YOUR_BIN_ID
X-Secret-Key: YOUR_KEY
Content-Type: application/json
    
      
    
      
    Public bins can be read by anyone. Keyless public bins can be changed or deleted only by the browser holding their HttpOnly owner cookie; private bins and other clients require the owner key. PUT replaces the full value; PATCH shallow-merges object fields.
